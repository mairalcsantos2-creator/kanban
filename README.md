# Kanban Rotina Agrícola

Kanban semanal da rotina de análise agrícola (segurança, produção, performance, gente, custos e rotinas). Página única em HTML, sem dependências nem etapa de build.

## Como publicar no Vercel

1. Importe este repositório em um projeto novo no Vercel.
2. Framework preset: **Other**. Deixe build command e output directory em branco.
3. Publique. O `index.html` da raiz é servido como página inicial.

## Observações

- Fora do claude.ai, os cartões ficam salvos apenas no navegador de quem usa (localStorage).
- A rotina inicial é uma proposta editável; o botão "Restaurar modelo da rotina" volta a ela.
